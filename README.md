# digitalcc.nl

Statische website van Digital Communication Controls (KvK 74794795), gehost op GitHub Pages met custom domain `digitalcc.nl`.

- `index.html`: homepage (diensten, werkwijze, contact)
- `privacy.html`: privacy- en cookieverklaring (geen cookies of tracking)
- Bedrijfsgegevens komen uit `~/Documents/Boekhouding/data/instellingen.json`.
- DNS staat bij TransIP. Alleen `@` A/AAAA en `www` wijzen naar GitHub Pages; de mailrecords blijven ongemoeid.

Wijzigen: bestand aanpassen, dan `git commit` en `git push`. GitHub Pages publiceert automatisch.
